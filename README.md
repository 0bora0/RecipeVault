# RecipeVault

## Short Description
RecipeVault is a ReactJS application that uses Firebase as a database and retrieves data from the Spoonacular API. Users can view detailed information about the fetched recipes. The application allows user registration, recipe addition, and viewing recipes added by other users. The service is deployed in the cloud on Render and can be accessed via the following link: [https://recipe-vault.onrender.com/](https://recipe-vault.onrender.com/).

## Demonstration
https://recipe-vault.onrender.com 

## Technologies
- React
- Firebase
- Spoonacular API
- React Router
- Bootstrap (for styling)
